## plateforme de billetterie événementielle.

# MyTiq est une plateforme moderne de billetterie événementielle qui permet aux utilisateurs d’acheter et gérer leurs billets facilement. Développée avec Laravel pour le backend et React pour le frontend, elle intègre Sanctum, API REST, et une gestion complète des événements et newsletters.
